## 📖 About The Repository

**College Workspace** is a complete collection of my **B.Sc. Information Technology** academic journey — notes, assignments, practicals, projects, and study resources, organized into subject folders for quick reference and easy sharing.

It keeps everything in one place: a single source of truth for my coursework, useful both for my own revision and for juniors and classmates looking for organized reference material.

<div align="center">

| | |
|---|---|
| 🎓 **Purpose** | Centralized academic notes & coursework archive |
| 🗂️ **Organization** | One folder per subject, plus an ESE exam folder |
| 📄 **Contains** | Notes, Assignments, Practicals, Projects & Study Resources |
| 🔄 **Status** | Actively updated as new coursework is completed |

</div>

